# Assignments

Work for each assignment lives here, organized by week/unit to match the course:

```
assignments/
└── week-01-intro-to-animation/
    ├── animation-student-survey/
    ├── make-a-flipbook/
    └── reflection-and-direction/
```

As new units open in the course, add a matching `week-XX-name/` folder here with one subfolder per assignment. See [docs/submitting-work.md](../docs/submitting-work.md) for what to put in each folder.
