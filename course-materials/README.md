## How to fill in the ⬜ items (5 minutes)

1. Open the [Schoology materials page](https://nmusd.schoology.com/course/8478718761/materials) while logged in.
2. **For PDFs/files:** click the file to download it, then upload it to the matching folder here (on GitHub: open the folder → **Add file → Upload files**).
3. **For web links:** right-click the link on Schoology → *Copy link address* → paste it into the folder's `links.md`.

Once added, flip the ⬜ to ✅ in the tables above.
