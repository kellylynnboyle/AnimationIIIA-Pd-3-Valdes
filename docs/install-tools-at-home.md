# Installing the Class Tools at Home

Two parallel toolset setups so you can work anywhere: the **official class tools** (same as the school lab) and **free alternatives** that open-or-approximate the same work if you don't have a license at home.

## Official class tools

| Tool | How to get it at home | Cost |
|---|---|---|
| **Toon Boom Harmony** | Use the *"Download Toon-Boom at Home!"* link on the [Schoology course page](https://nmusd.schoology.com/course/8478718761/materials) — it has the class's download/license instructions. Otherwise: [21-day free trial](https://www.toonboom.com/products/harmony) or [student pricing](https://www.toonboom.com/education) | Class link / trial / student rate |
| **Storyboard Pro** | [21-day free trial](https://www.toonboom.com/products/storyboard-pro) or [student pricing](https://www.toonboom.com/education) | Trial / student rate |
| **Adobe Photoshop** | Check whether NMUSD provides student Adobe accounts (ask your teacher — many districts do). Otherwise [Creative Cloud student plan](https://www.adobe.com/creativecloud/buy/students.html) | District account / student rate |

> **Tip:** Install the **same version** of Harmony as the school lab if you can — scene files (`.xstage`) saved in a newer version may not open in an older one at school.

## Free parallel toolset

No license at home? These free tools cover the same kind of work:

| Class tool | Free parallel | Notes |
|---|---|---|
| Toon Boom Harmony | [OpenToonz](https://opentoonz.github.io/e/) or [Krita](https://krita.org/) | OpenToonz is closest in workflow (used by Studio Ghibli); Krita has a friendly frame-by-frame animation mode. Neither opens `.xstage` files — export/import image sequences or video to move work between home and school. |
| Storyboard Pro | [Storyboarder](https://wonderunit.com/storyboarder/) | Free, simple boarding + animatic tool. Export boards as images/PDF to continue in Storyboard Pro at school. |
| Adobe Photoshop | [Krita](https://krita.org/) or [Photopea](https://www.photopea.com/) | Photopea runs in the browser (nothing to install) and **opens and saves real `.psd` files**, so work moves cleanly between home and school. |

## Moving work between the two systems

The free tools can't open Toon Boom's native files, so use portable formats as the bridge:

- **Line art / frames:** export as `.png` image sequence
- **Boards:** export as `.pdf` or numbered `.jpg`s
- **Animatics / tests:** export as `.mp4` (H.264)
- **Digital paintings:** save as `.psd` (Photopea and Krita both handle it)

Commit the portable exports to this repo along with your native project files — then whichever system you sit down at, you can pick the work back up.
