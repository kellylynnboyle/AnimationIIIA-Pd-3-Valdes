## Essential shortcuts

| Action | Windows | Mac |
|---|---|---|
| Brush | B | B |
| Eraser | E | E |
| Lasso | L | L |
| Move | V | V |
| New layer | Ctrl+Shift+N | ⌘⇧N |
| Duplicate layer | Ctrl+J | ⌘J |
| Merge down | Ctrl+E | ⌘E |
| Transform | Ctrl+T | ⌘T |
| Brush size down / up | [ / ] | [ / ] |
| Fill with foreground | Alt+Backspace | ⌥Delete |
| Deselect | Ctrl+D | ⌘D |
| Undo | Ctrl+Z | ⌘Z |
