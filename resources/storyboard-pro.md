## Working with audio (from the class links)

- **Import sound clips:** File → Import → Sound Clips, or right-click an audio track in the timeline → Import Sound Clips. Supported formats include `.wav`, `.aif`, `.mp3`.
- **Play audio tracks:** enable audio playback in the Playback toolbar (speaker icon) before pressing play; each audio track can be muted/soloed from the timeline.
