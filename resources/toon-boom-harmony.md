## Frequently used shortcuts (defaults)

| Action | Windows | Mac |
|---|---|---|
| Brush | Alt+B | ⌥B |
| Pencil | Alt+/ | ⌥/ |
| Eraser | Alt+E | ⌥E |
| Select | Alt+S | ⌥S |
| Transform | Shift+T | ⇧T |
| Onion skin toggle | Alt+O | ⌥O |
| Add drawing (frame) | F | F |
| Play | Shift+Enter | ⇧Return |
| Zoom in / out | 2 / 1 | 2 / 1 |
| Reset view | Shift+M | ⇧M |
| Undo | Ctrl+Z | ⌘Z |

*(The class PDF on Schoology is the authoritative list — add anything from it you use a lot.)*
